# 🔐 Authentication & Authorization Module

The Authentication module governs entry security for the entire application, verifying user identity before granting access to resources defined in the [User Management Module](/docs/user).

---

## 📂 Detailed Feature Structure (Nested Structure)

The Auth module is organized into two nested feature groups:

### 1. Login & Security Flows (`login-flow/`)
- 📖 [**Login Flow & Session Creation**](/docs/auth/login-flow) — Email/Password authentication, temporary lockouts after 5 failed attempts.
- 📖 [**Multi-Factor Authentication (MFA / TOTP)**](/docs/auth/login-flow/mfa) — Enhanced protection using 6-digit TOTP from Authenticator apps or SMS.

### 2. OAuth & Session Management (`oauth-sso/`)
- 📖 [**Social Single Sign-On (Google & GitHub SSO)**](/docs/auth/oauth-sso/google-github) — One-click login via Google Workspace or GitHub.
- 📖 [**Session Management & JWT Token Lifecycle**](/docs/auth/oauth-sso/session-management) — Remote sign-out, token refresh logic, and privilege revocation.

---

## 🔗 Cross-Functional Dependencies

- Successful authentication loads initial data from the [User Profile](/docs/user/profile-management) and evaluates [RBAC Permissions](/docs/user/rbac-permissions).
- If an account is locked via the [User Lifecycle](/docs/user/rbac-permissions/user-lifecycle), the login engine blocks access and invalidates active [JWT Sessions](/docs/auth/oauth-sso/session-management).
