## How to write a flow page

Keep each page to the same four sections so they stay comparable:

1. **Trigger** — what starts the flow.
2. **Sequence** — a diagram of the actors and calls.
3. **Steps** — the numbered walkthrough, with the rules that apply at each step.
4. **Failure cases** — what can go wrong and what the user sees.
